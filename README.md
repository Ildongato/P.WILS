# P. Wils website

Website preview published from the root of `main` with GitHub Pages.

Live URL: https://ildongato.github.io/P.WILS/

## Pages

- Home and language entry: `index.html`
- Products, custom specifications and product enquiries: `producten.html`
- Quality and documentation: `kwaliteit.html`
- Company, directors, production, full history, careers contact and news: `bedrijf.html`
- Contact, departments and directions: `contact.html`
- Privacy information: `privacy.html`
- Sector directory: `sector.html`
- Compatibility route: `bereikbaarheid.html` forwards to Contact.

This is a static website. Product and contact forms prepare a draft for the visitor's
own email application; they do not send messages through a backend. Certificates
and supplementary language PDFs are included with the website assets.

Push approved website changes to `main` to republish automatically. This Pages
preview remains excluded from search indexing while the original domain is in use.
Local design proposals, source reviews and editorial notes are not included.

The current website retains Host Grotesk. Separate font experiments are proposals.
Font, icon and map attributions are retained with the assets and map UI.
