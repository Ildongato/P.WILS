# P. Wils website

Current website preview, published from the root of `main` with GitHub Pages.

Live URL: https://ildongato.github.io/P.WILS/

## Pages

- Home and language entry: `index.html`
- Products and custom requests: `producten.html`
- Quality and documentation: `kwaliteit.html`
- Company and history: `bedrijf.html`
- Contact and directions: `contact.html`

This is a static site. Product and contact forms prepare an email in the visitor’s mail application. The current original Wils site hosts the supplementary news, jobs, sector links, privacy statement and external language/certification PDFs.

Push website changes to `main` to republish automatically. The Pages preview remains excluded from search indexing while the original domain is in use. Original local design/review materials are not part of this public repository.

Font, icon and map attributions are retained with the assets and map UI.
